# Dictado sintético

`dictado-sintetico.wav` es voz **sintética** (texto a voz, 20 segundos, 16 kHz mono) leyendo `dictado-sintetico.txt`, con datos inventados. No es la voz de ninguna persona ni contiene datos de ningún paciente. Sirve para probar la transcripción en un navegador sin grabar a nadie.

En este repositorio no se guarda ningún audio real.
