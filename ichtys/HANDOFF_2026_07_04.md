## 5. Limitaciones conocidas / deuda técnica

| Item | Descripción | Prioridad |
|------|-------------|-----------|
| E3 PDF | El "PDF" es HTML print-ready — el usuario hace Ctrl+P. No genera PDF server-side. Para PDF real se necesita `@react-pdf/renderer` o puppeteer. | Media |
| T3 Endpoint diff | Usa matching posicional, no por contenido. Si se inserta un endpoint en el medio, los siguientes aparecen como "modificados". Para v2: LCS sobre endpoints por tipo. | Baja |
| E2 Enterprise gate | El banner de enmienda se muestra a todos. El diseño original planteaba gatearlo por plan CRO premium. No hay billing implementado aún. | Baja |
| T2 Admin UI | `updateOrgRagConfig()` existe pero no hay UI admin para slider de threshold/topK. Solo configurable vía DB directo. | Media |
| SD Scheduler | `checkAndRecoverStuckDocs()` existe pero no hay job scheduler. Hay que llamarlo manualmente o desde un cron externo. | Media |
